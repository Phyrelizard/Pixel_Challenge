Ascend Audio Placeholder Pack
=============================

This pack creates the new Ascend-specific audio file names for the redesigned Ascend game.
Most files are intentionally 0-byte placeholders so the directory structure and filenames exist.

IMPORTANT:
- Do not overwrite real/nonzero audio files with these placeholders.
- If extracting manually, choose "skip existing files" if prompted.
- as_music_gameplay.ogg is NOT included here because your project already has a real gameplay music file.

Expected structure:

assets/audio/splash/splash_music_ascend.ogg

assets/audio/ascend/as_music_gameplay.ogg          (existing real file, not included)
assets/audio/ascend/as_music_victory.ogg
assets/audio/ascend/as_band_build.wav
assets/audio/ascend/as_move_forward.wav
assets/audio/ascend/as_move_backward.wav
assets/audio/ascend/as_jump.wav
assets/audio/ascend/as_player_hit.wav
assets/audio/ascend/as_warp.wav
assets/audio/ascend/as_wall_build.wav
assets/audio/ascend/as_laser_fire.wav
assets/audio/ascend/as_wall_hit.wav
assets/audio/ascend/as_wall_miss.wav
assets/audio/ascend/as_launch.wav
assets/audio/ascend/as_glass_break.wav
assets/audio/ascend/as_game_over.wav
assets/audio/ascend/as_winner.wav

Recommended file types:
- OGG for music/long loops
- WAV for short sound effects
